## Hoja de iconos

Cuadrícula 4 × 4, celdas de 256 × 256 px. Orden: ficha, check, candado, corona; copiar, jugador vacío, altavoz, engranaje; flecha izquierda, flecha derecha, medalla 1, medalla 2; medalla 3 y tres celdas vacías. Márgenes transparentes entre iconos; pendiente recortarlos e importarlos al montar la interfaz.

Las ilustraciones del tutorial están contenidas en una franja de 560 px de alto, centrada en lienzo de 1536 × 1024. El brillo cercano a los objetos usa alfa parcial; no hay fondo sólido ni patrón de cuadros.

[Prompts](PROMPTS.md) · [Manifest de archivos y dimensiones](manifest.json) · [Bocetos del menú](../README.md).

Este trabajo entrega recursos sueltos; no monta pantallas ni modifica Unity.
