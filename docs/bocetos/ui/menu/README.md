Crear sala conduce directamente a la sala de espera; seleccionar personaje está integrado en el menú principal. La tienda se abre desde la sala de espera. Cómo se juega usa una única plantilla de seis páginas; su imagen muestra la primera.

[Decisiones de diseño, estados y seis textos del tutorial](DISENO.md) · [Prompts y referencias](PROMPTS.md) · [Pedido de imágenes para montar el menú](PEDIDO_IMAGENES.md).

«TRIVIAS» es un nombre de trabajo. Datos y reparto visual de personajes gratuitos/de pago son ilustrativos; la regla vigente es seis gratuitos y cuatro de pago y aún falta decidir cuáles. Los bocetos no modifican la interfaz implementada.
