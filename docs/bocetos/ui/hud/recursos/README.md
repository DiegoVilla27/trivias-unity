Sin texto, escenario, suelo, sombras proyectadas ni marcos. Corrección aplicada a la misma hoja: eliminar el fondo y los halos de color, conservar los objetos y ajustar cada uno a un máximo de 384 × 384 píxeles dentro de su celda.
