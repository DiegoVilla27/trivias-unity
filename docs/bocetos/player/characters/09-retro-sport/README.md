# 09 — Retro Sport

[Boceto completo A-pose](retro-sport-a-pose.png) · [Prompt](prompt.md)

Personaje completo con el atuendo y calzado Retro Sport previamente diseñados. Peinado: Coleta alta castaña. Mantiene la identidad, las proporciones y el estilo cute de Blue Tracksuit.

Una única lámina de ocho vistas: frente, espalda, perfiles opuestos, superior, inferior y tres cuartos delantero y trasero. Brazos bajados en A-pose. Pelo, ropa y zapatos aparecen integrados en el personaje; el calzado cubre el pie.

Las antiguas referencias separadas de ropa, calzado y pelo fueron eliminadas. Este boceto completo es la referencia vigente del personaje.

Son bocetos artísticos; al modelar se comprobará la coherencia entre vistas y el encaje. En este trabajo solo se modifica documentación.
