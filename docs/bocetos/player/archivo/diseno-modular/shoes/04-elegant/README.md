# 04 — Elegant

Zapato de vestir marrón oscuro, cordones sencillos y suela baja.

[Boceto de cuatro vistas](elegant.png) · [Prompt](prompt.md) · [Ropa correspondiente](../../clothes/04-elegant/README.md)

Una sola lámina de un zapato aislado visto de frente, talón y ambos perfiles, sin pie ni player. Diseñado para envolver el pie corto, ancho y redondeado de la [base](../../base/personaje-base-t-pose.png): puntera, empeine, laterales, talón y planta cubiertos; única entrada por el tobillo.

Mantener el pie original completo dentro, con grosor de material y holgura interior. Al modelar, comprobar la cavidad, la suela bajo el pie, el collar alrededor del tobillo y el solape con el pantalón durante la animación. El segundo zapato se obtiene por simetría, adaptando cierres si corresponde. Estas vistas son bocetos visuales, no una prueba dimensional del encaje.
