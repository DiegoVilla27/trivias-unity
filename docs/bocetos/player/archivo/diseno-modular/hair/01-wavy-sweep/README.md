# 01 — Wavy Sweep

Ondulado castaño original, mechones grandes y flequillo lateral.

[Boceto de cuatro vistas](wavy-sweep.png) · [Prompt](prompt.md)

Una única lámina de pelo aislado: frente, espalda y dos perfiles. Usa la [cabeza base](../../base/personaje-base-t-pose.png) como referencia de volumen y el [pelo original](../../../poses-originales/personaje-t-pose.png) como referencia de acabado. Sin cabeza, piel, player ni ropa.

Conservar el cráneo completo debajo de la pieza; respetar frente, cejas, orejas y nuca. Las vistas son referencias artísticas y pueden tener variaciones de proyección y detalle; comprobar orientación anatómica, cavidad interior y holguras sobre la malla al modelar. No representan un encaje geométrico ya verificado.
