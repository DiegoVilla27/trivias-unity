## Encaje y cobertura

- Una imagen por estilo, con un único zapato en cada vista: frente, talón y perfiles opuestos. El otro pie se resuelve por simetría al modelar.
- Respetar el pie corto, ancho, alto de empeine y de puntera redondeada de la base; no reducir el pie para meterlo en el zapato.
- Cubrir puntera, empeine, laterales, talón y planta. Solo se deja la abertura superior para el tobillo; no hay sandalias, talones abiertos ni perforaciones que expongan piel.
- La zapatilla de pijama y el zapato de chef tienen talón cerrado. Las botas usan caña corta para respetar las piernas del personaje.
- Usar el mismo pie interior como referencia para todos los estilos, grosor exterior moderado y suela bajo la planta. Comprobar el collar y el solape con el pantalón al modelar y animar.
- Mantener paletas apagadas, formas redondeadas y detalles simples. Los bocetos muestran únicamente calzado, sin player, pies, calcetines ni ropa.

Son referencias visuales, no patrones dimensionales. El encaje geométrico exacto se verificará sobre la malla del pie al modelar. Todo este trabajo permanece en docs.

Cada carpeta incluye el prompt utilizado con imagegen integrado y un enlace a su ropa correspondiente.
