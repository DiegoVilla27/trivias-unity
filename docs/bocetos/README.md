## Uso de las referencias

Estos son bocetos artísticos, no modelos 3D ni planos dimensionales certificados. Comprobar coherencia de proporciones y proyecciones al desarrollar las piezas. Las reglas y el alcance del juego se consultan en el [GDD](../GDD.md); los detalles que aparecen en imágenes exploratorias no añaden funcionalidades por sí solos.
